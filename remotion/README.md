# remotion/

Tempat komposisi video Remotion. Kontrak data ada di `skills/semburat-design/references/remotion-spec.md`
dan contoh props di `props.example.json`.

Saran urutan: selesaikan loop artikel dan template gambar dulu, baru mulai video.
Mulai dari satu komposisi (`BreakingTrending`), render lokal, baru pindah ke GitHub Actions
setelah tahu lama render dan sisa kuota menit.
Periksa syarat lisensi Remotion terbaru untuk penggunaan komersial sebelum monetisasi.
