# SEO Content Skill

## Goal

Make verified editorial content discoverable.

## Workflow

1. Identify search intent.
2. Determine primary topic/entity.
3. Build semantic keyword set.
4. Improve title/dek.
5. Improve heading hierarchy.
6. Add useful internal links.
7. Generate metadata.
8. Validate canonical URL.
9. Validate structured data.
10. Check readability.

## Rules

- No keyword stuffing.
- No unsupported claims.
- Do not distort headlines for CTR.
- Search intent must match article substance.
- Prefer useful information over SEO filler.

## Output

- seo_title
- meta_description
- slug
- primary_topic
- secondary_topics
- suggested_internal_links
- schema_type
- image_alt_text
