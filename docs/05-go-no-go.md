# 05 — Gerbang Go / No-Go

| #   | Gerbang                                | Syarat lulus                                                                                            |
| --- | -------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| 1   | **Boleh deploy staging**               | Semua tes Tahap A lolos · tidak ada secret di repo · kill switch terbukti                               |
| 2   | **Boleh rilis publik**                 | Tahap B dan C selesai · ≥ 10 artikel lolos review dengan kualitas konsisten · halaman kebijakan lengkap |
| 3   | **Boleh auto-publish (risiko rendah)** | Syarat di `04-soft-launch-playbook.md` terpenuhi · koreksi fakta besar jarang                           |
| 4   | **Boleh tambah niche/kanal**           | Traffic organik naik 2 bulan berturut-turut · beban review terkendali · biaya per artikel diketahui     |
| 5   | **Boleh video & voice over rutin**     | Loop artikel stabil · ada pendapatan/anggaran · syarat lisensi audio penyedia dicatat                   |
| 6   | **Boleh menerima sponsor**             | Label "Konten Bersponsor" siap · kebijakan editorial independen dipublikasikan                          |

Aturan: jika satu syarat gagal, **jangan lompat** ke gerbang berikutnya. Perbaiki dulu, catat di log tes, uji ulang.
