# SEMBURAT Editorial Policy

## Editorial identity

SEMBURAT should be:

- fast without being reckless
- concise without losing context
- informative without clickbait
- automated without becoming impersonal
- transparent about sources

## Headline

Prefer:

- specific
- factual
- readable
- informative

Avoid:

- fabricated urgency
- unsupported superlatives
- deceptive curiosity
- claims stronger than evidence

## Sources

Prefer source diversity for consequential claims.

Store:

- URL
- publisher
- access time
- publication time where available
- source type
- license/usage state
- evidence references

## Quotes

Do not fabricate quotes.

If paraphrasing, do not format the paraphrase as a direct quote.

## Images

Every reused image must have a provenance/license state.

Possible states:

- owned
- licensed
- public_domain
- permitted
- generated
- unknown
- restricted

`unknown` and `restricted` must not automatically become public assets.

## AI disclosure

Keep internal generation metadata even if the public UI does not expose every implementation detail.

## High-risk content

Route to human review when:

- evidence conflicts
- allegation is involved
- health/medical advice is involved
- financial claims may cause material harm
- private/sensitive information is present
- source reliability is uncertain

## Corrections

Corrections should preserve an audit trail.

Never silently overwrite a materially published factual error without recording the correction.

## Indonesian style

Default:

- natural Bahasa Indonesia
- avoid unnecessary jargon
- explain technical terms on first use
- use concise paragraphs
- use active voice where natural

## Editorial quality gate

Minimum conceptual gate:

```text
Source coverage >= required threshold
AND
Material claims verified
AND
No unresolved critical contradictions
AND
Asset provenance valid
AND
Risk policy passed
```

If not, publish state must remain blocked.
