# pages/ — Draf Halaman Wajib

Draf awal untuk halaman yang diwajibkan PRD (bagian 31 dan 33). Cara pakai:

1. Ganti semua teks dalam `[KURUNG SIKU]` (nama, email, domain, tanggal).
2. Sesuaikan dengan praktik **yang benar-benar Anda jalankan**. Jangan menulis janji yang tidak dikerjakan.
3. Salin ke `apps/web/src/pages/` (Astro) atau konten halaman Anda.

Catatan: ini draf umum, **bukan nasihat hukum**. Privacy dan Terms sebaiknya ditinjau ahli hukum, terutama sebelum memakai iklan, afiliasi, newsletter, atau mengumpulkan data pengguna.
